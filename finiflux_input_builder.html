FINIFLUX input builder

Set the model options, enter your radon sampling points and the properties of each reach between them, and download a ready-to-run FINIFLUX.xlsx. The file follows the layout of the FINIFLUX template (sheet Tabelle1) and works with the MATLAB model and the Python version.

Sampling points and reaches

Each row is a radon sampling point. The reach values in a row describe the stretch from that point to the next one, so the last point has no reach. You can paste a block of cells copied from Excel into any field; it fills the cells to the right and below and adds rows when needed. Forgot a point? Use + at the end of a row to insert a point below it. This splits that reach in two, and the new reach takes over its properties.

Set to

Choose the type of each reach first. A normal reach has no surface inflow, and its inflow values are set to 0. For a tributary reach, fill in the highlighted inflow discharge, inflow length and inflow radon. The length of a tributary reach must equal its inflow length, so the location of the next point is set automatically to the previous point's location plus the inflow length (shown in orange and locked). A tributary is usually entered as a short reach of about 1 m at the confluence.
